# Marketeer Forever 1.0.73

- Added Baganator support for the red, yellow, and green bag selling-rule markers, including refreshing when the bag opens.
- Clarified that the AH premium over vendor value is expressed as a percentage of the AH price. Existing calculations and rules are unchanged.
- Item-history searches now start with all available observations rather than retaining a previous time filter.
- Empty crafting filters now default to zero; a maximum spend of zero means no limit.
- Simplified the crafting gap column label.

The separate Marketeer Forever Data Updater supplies market prices and history. Download it from the GitHub release, choose your market, and reload the game after updating. Prices and activity from AHledger (ahledger.com).
