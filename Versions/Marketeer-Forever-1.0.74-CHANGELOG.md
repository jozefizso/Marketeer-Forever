# Marketeer Forever 1.0.74

- Added an option to show bag selling markers only at the auction house or a vendor. Hold Shift to temporarily show them elsewhere.
- Excluded items no longer show selling markers and are skipped by Marketeer's vendor selling.
- Added per-rule junk settings and a Sell junk button beside the vendor's Buyback tab. Quest items are skipped.
- Added a one-time notice explaining how the separate data updater supplies sales estimates and price history.

Get the separate Marketeer Forever Data Updater from the project page, select your market, and run it daily to keep market data current. Prices and activity from AHledger (ahledger.com).
