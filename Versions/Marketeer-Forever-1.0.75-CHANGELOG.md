# Marketeer Forever 1.0.75

- Added ArkInventory support for selling-rule markers, including refreshing when bags open, close, or change.
- Items worth more to a vendor now use the lowest configured Vendor rule; eligible items without an auction price use that rule as well.
- Added an Excluded only view so you can find exclusions even when those items are not in your bags.

The Marketeer Forever Data Updater supplies market sales estimates and price history. Prices and activity from AHledger (ahledger.com).
