# Marketeer Forever 1.0.71

- Added searchable item price-history charts and a resizable Marketeer panel.
- Added price trends to item tooltips and improved comparison-tooltip placement.
- Added configurable AH or vendor methods for bag-value estimates, bag markers, and support for EllesmereUI Bags.
- Improved auction tab labels, bag positioning and in-combat marker updates.
- Moved Marketeer confirmations and dropdowns out of Blizzard's shared dialog systems to reduce UI conflicts.

Market data is supplied separately by the Marketeer Forever Data Updater. Download the updater from the project GitHub page, select your market, and reload the game after updating. Prices and activity from AHledger (ahledger.com). History is limited to data collected for your market and may have gaps.
