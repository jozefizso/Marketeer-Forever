# Marketeer Market Data companion

`build_data_addon.py` makes a standalone CurseForge ZIP containing the item-name catalog and a load-on-demand addon for each supported region, ruleset and faction. Each market includes the latest validated AHledger price table, price-history points and trend summaries. Values use the existing schemas and source timestamps; this is price history and estimated sales pace, not hourly sales counts. Marketeer loads only the current market. Its own SavedVariables are unchanged.

The new companion uses `MarketeerMarketSnapshots` and `MarketeerSnapshot_*` folders, separate from the old updater's `MarketeerForeverData`. When both sources exist, Marketeer uses the newest valid source for the current market. A missing, disabled, empty or stale companion does not prevent the existing data source from working.

`publish_data_addon.py` prepares all 32 markets, validates the ZIP, then submits a release through the CurseForge Upload API. A dry run accepts `--dry-run` and needs no credentials. Unattended uploads require the upload token in an owner-only regular file and a persistent state file. The publisher waits at least two hours between submissions and checks a public project listing for the previous release; if it is missing, the listing is unavailable, or an upload's outcome is uncertain, it fails closed. The listing is a third-party mirror, not an authoritative moderation-status API; a missing file requires author review. Run under `flock` so jobs cannot overlap. The scheduler checks every five minutes but submits no more often than every two hours; availability depends on CurseForge review, client update settings and `/reload`.

On November 18, 2026, the owner approved the live switch after the first data release was installed and the in-game layout checked. The two-hour publisher schedule was enabled; data file 9686542 and main-addon 1.0.97 file 9686652 were submitted for CurseForge review. The main file declares the data project as a required CurseForge dependency, while the addon still supports legacy updater data.
