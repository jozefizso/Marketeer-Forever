# Marketeer Forever 1.0.82

- Added Farm to the Marketeer widget, with monster loot value, demand-weighted ranking, level and name filters, and detailed drop tables.
- Added Find sources for recorded monster, gathering, vendor, quest, and other item sources, with links to monster loot.
- Added a Recipes browser with materials, scan-based costs and profit estimates, estimated daily sales, and item-source links.
- Added inventory shortcuts, shortcut hints, and a Shift-hover creature card with drop rates, prices, and a link to Farm.
- Improved crafting material navigation and protected bag-frame handling.

Loot and source data are bundled as an incomplete Wowhead snapshot, including some Classic Era fallback rates. Estimated proceeds assume one item per recorded drop and are not guaranteed. Market prices and estimated sales are provided separately by the Marketeer Forever Data Updater using AHledger data; run the updater and reload to refresh them.
